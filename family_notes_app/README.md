# 🏠 Семейные заметки (Family Notes)

Десктоп-приложение для совместной работы с заметками в семейных или рабочих пространствах.

![Python](https://img.shields.io/badge/Python-3.13.5-blue)
![PyQt6](https://img.shields.io/badge/PyQt6-6.4+-green)
![SQLite](https://img.shields.io/badge/Database-SQLite-orange)

## 📋 Функционал

### ✅ Реализованные функции:

1. **Авторизация и регистрация**
   - Регистрация с проверкой данных
   - Вход по логину и паролю
   - Хеширование паролей (SHA-256)

2. **Создание пространств**
   - Создание собственных пространств
   - Название и описание пространства
   - Автоматическая генерация кода приглашения

3. **Присоединение по ссылке или QR-коду**
   - Ввод 8-символьного кода приглашения
   - Генерация QR-кода для приглашения

4. **Работа с заметками**
   - Создание заметок
   - Редактирование заметок
   - Удаление заметок
   - Просмотр автора и времени изменения

5. **Управление участниками**
   - Просмотр всех участников пространства
   - Исключение участников (только для владельца)
   - Отображение роли (владелец/участник)

6. **Логирование действий**
   - Запись всех действий в базу данных
   - Просмотр истории действий в пространстве
   - Отслеживание: кто, когда и что делал

7. **Множественные пространства**
   - Каждый пользователь может создавать свои пространства
   - Участие в нескольких пространствах одновременно

## 🚀 Инструкция по запуску

### Требования
- **Python 3.13.5** (или совместимая версия 3.10+)
- **PyCharm** (рекомендуется) или другая IDE
- Операционная система: Windows 10/11

### Шаг 1: Установка Python

1. Скачайте Python 3.13.5 с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** поставьте галочку "Add Python to PATH"
3. Проверьте установку в терминале:
   ```bash
   python --version
   ```

### Шаг 2: Настройка проекта в PyCharm

1. Откройте PyCharm
2. Выберите **File → Open** и откройте папку `family_notes_app`
3. Настройте интерпретатор Python:
   - **File → Settings → Project → Python Interpreter**
   - Нажмите ⚙️ → **Add Interpreter → Add Local Interpreter**
   - Выберите **Virtualenv Environment** → **New**
   - Base interpreter: выберите Python 3.13.5
   - Нажмите **OK**

### Шаг 3: Установка зависимостей

**Вариант A: Через терминал PyCharm**

Откройте терминал (View → Tool Windows → Terminal) и выполните:

```bash
pip install -r requirements.txt
```

**Вариант B: Через интерфейс PyCharm**

1. Откройте файл `requirements.txt`
2. PyCharm предложит установить зависимости - нажмите **Install**

### Шаг 4: Запуск приложения

**Через PyCharm:**
1. Откройте файл `main.py`
2. Правый клик → **Run 'main'**
3. Или нажмите **Shift + F10**

**Через терминал:**
```bash
python main.py
```

## 📦 Сборка EXE файла

### Способ 1: Через скрипт (рекомендуется)

```bash
python build_exe.py
```

### Способ 2: Вручную

1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```

2. Соберите приложение:
   ```bash
   pyinstaller --onefile --windowed --name=FamilyNotes main.py
   ```

3. EXE файл будет создан в папке `dist/FamilyNotes.exe`

### Примечания к EXE:
- При первом запуске EXE в той же папке будет создана база данных `family_notes.db`
- Для переноса на другой компьютер копируйте только EXE файл
- Антивирусы могут блокировать собранные EXE - добавьте в исключения

## 🗄️ Структура базы данных

### Таблица `users` - Пользователи
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| username | TEXT | Уникальное имя пользователя |
| password_hash | TEXT | Хеш пароля (SHA-256) |
| email | TEXT | Email пользователя |
| created_at | TIMESTAMP | Дата регистрации |

### Таблица `spaces` - Пространства
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| name | TEXT | Название пространства |
| description | TEXT | Описание |
| owner_id | INTEGER | ID владельца (FK → users) |
| invite_code | TEXT | Уникальный код приглашения |
| created_at | TIMESTAMP | Дата создания |

### Таблица `space_members` - Участники пространств
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| space_id | INTEGER | ID пространства (FK → spaces) |
| user_id | INTEGER | ID пользователя (FK → users) |
| joined_at | TIMESTAMP | Дата присоединения |

### Таблица `notes` - Заметки
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| space_id | INTEGER | ID пространства (FK → spaces) |
| title | TEXT | Заголовок заметки |
| content | TEXT | Содержимое |
| author_id | INTEGER | ID автора (FK → users) |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата изменения |

### Таблица `activity_logs` - Логи действий
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| user_id | INTEGER | ID пользователя (FK → users) |
| note_id | INTEGER | ID заметки (FK → notes) |
| space_id | INTEGER | ID пространства (FK → spaces) |
| action | TEXT | Тип действия |
| details | TEXT | Подробности |
| timestamp | TIMESTAMP | Время действия |

## 🎨 Использование приложения

### Регистрация
1. Запустите приложение
2. Нажмите "Зарегистрироваться"
3. Заполните форму (мин. 3 символа для логина, 6 для пароля)
4. После успешной регистрации — войдите в систему

### Создание пространства
1. На главной странице нажмите "Создать пространство"
2. Введите название и описание
3. Получите уникальный код приглашения

### Приглашение участников
1. Откройте пространство
2. Нажмите "Пригласить"
3. Скопируйте код или покажите QR-код участнику

### Присоединение к пространству
1. На главной странице нажмите "Присоединиться по коду"
2. Введите 8-символьный код приглашения

### Работа с заметками
- **Создать**: кнопка "Новая заметка" в пространстве
- **Редактировать**: кнопка ✏️ на карточке заметки
- **Удалить**: кнопка 🗑️ на карточке заметки

## ❓ Решение проблем

### Ошибка "No module named 'PyQt6'"
```bash
pip install PyQt6
```

### Ошибка "No module named 'qrcode'"
```bash
pip install qrcode[pil]
```

### Приложение не запускается
1. Проверьте версию Python: `python --version`
2. Переустановите зависимости: `pip install -r requirements.txt --force-reinstall`

### EXE не запускается или блокируется антивирусом
1. Добавьте файл в исключения антивируса
2. Или запустите от имени администратора
